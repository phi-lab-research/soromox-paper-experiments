\caption{\textbf{Model-based control enables pose tracking and automatic gain tuning.}
(\textbf{A}) A two-segment robot tracks a figure-eight pose reference under operational-space impedance control. Solid and faint shapes show recorded motion. The green path and oriented ring indicate the desired trajectory and instantaneous pose. Plots show position and geodesic orientation errors.
(\textbf{B}) Snapshots compare a single-segment robot before and after operational-space gain tuning at $t=5$\,s. White dots mark current tips and green rings their target. Curves compare the initial run nearest the median loss with the best optimized run from a different initialization. Shading spans pointwise minimum--maximum errors across six initial gain sets. Plot markers identify the snapshot time.}
